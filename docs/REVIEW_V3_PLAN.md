- 分工：服务端负责 V3 文本协议和提示词；Android 负责正文、复习表、持久化与兼容；独立复核检查验收风险。
- 界面提供全课时间导览、Markdown 及公式正文、最早当前课堂原文入口、逐轮任务和完成标准；首页显示完成数。进度立即保存，全部完成移出待办但保留材料，取消恢复待办。
- Android 本地验证：早期 `ReviewPipelineTest` 13/13 和 `PendingReviewsTest` 1/1；真正缺失新增字段的自编 V2 JSON 兼容测试 1/1；后续旧内容身份判断新增方法 1/1；最终纯文字请求测试 1/1，且最终 Kotlin 编译通过。各次为针对性执行，不代表全量测试。此前识图相关模拟测试及代码已撤出，不计入最终验证。
