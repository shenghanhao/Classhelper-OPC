# V2 课堂复习验收记录

日期：2026-11-04。分支：`codex/opc-study-agent`。回退点：`codex/checkpoint-before-review-v2-20261104`（`774cdd3`）。

## 已实现路径

1. 设置 → 课程上下文：建立课程卡片、填写背景和术语，将课堂归入同一课程。
2. 设置 → 复习服务：配置自己的 HTTPS 代理地址与可选代理访问令牌。供应商 API Key 仅留服务端。
3. 已结束课堂 → 课程复习：预览本课、同课程历史文字、课堂标注与板书索引，明确同意后生成。
4. 全课导览/分区 → 简明知识点 → 全课复习方案与建议日期。点击原文索引导航到对应课堂段落；点击板书索引打开本地图片预览。
5. 首页待复习 → 进入材料 → 标记已复习：移出待办，材料保留。未配置网络时仍可查看已有材料。

## 真实模型运行

- 使用 `deepseek-flash`；2026-11-04 23:30（北京时间）开始。
- 只有两节自编力学材料；没有真实课堂、图片字节、录音或私人课表。
- 8 次供应商请求：1 次导览、6 个知识单元、1 次完整方案。
- 输出 3 个区间、6 个知识单元、6 个复习步骤；3 处板书索引、6 处历史原文引用；没有课堂例子的单元返回 `null`。
- 真实返回已作为明确标注 synthetic 的回放夹具：`class-memory/android/app/src/test/resources/review-v2-synthetic-deepseek.json`。它不是预置给产品用户的演示结果。
- 依据供应商返回用量与当日核验的官方高峰价格，保守估算 0.109542 元。实际账单可能因时段/缓存更低；这不是账单核对。用户授权总额 10 元，工具逐次预留最大输出成本后才发送请求；8 次均有 usage，未触及上限。
- 输入/输出没有人为字数、段数或固定 `max_tokens` 上限；实际模型容量、超时与请求限流仍有效。模型截断明确失败，不将半份结果保存为完整方案。
- 事实正确性仅对合成样本抽查；本次不是长课堂质量评估，也不能证明长期费用、吞吐和所有课程效果。

## 环境关口与明早清单

本轮未生成/安装新 APK、未改 GitHub Release、未部署公网代理、未执行手机 UI 测试。旧 Release 不包含本轮 V2 功能。

手机分析需一个可访问的 HTTPS 代理。在本机验证 API Key 不代表手机已连通；App 设置不能直接填写 DeepSeek 地址或其 API Key。后续获得出包/设备和服务环境授权后：

1. 生成候选 Debug/OPC 包，核对版本与并存身份，再安装指定设备。
2. 配置 HTTPS 代理，用自编材料确认上传预览、真实生成与取消/失败提示。
3. 点击本课/历史原文、板书索引；返回后检查材料和任务仍在。
4. 标记已复习，回首页确认待办消失，重开仍能查看；完成后冻结功能。

问答仅预留 `ReviewQaScope`（区间或全课）；图像理解、自动题库、复杂计划不在本次范围。
